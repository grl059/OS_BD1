🧠 Компьютерийн «тархи» өгөгдлөө хэрхэн хадгалдаг вэ?

Үйлдлийн системийн цөм (kernel) таван энгийн «хайрцаг»-аар мэдээллээ зохион байгуулдаг. Код мэдэх шаардлагагүй – товч дараад юу болохыг нь хар.

1. Доороос нэг бүтцийг сонго
2. ▶ «Жишээ үзүүл»-ийг дар, эсвэл өөрөө товчийг дар
3. «Юу болов?» хэсгээс тайлбарыг унш
Юу болов?
Одоохондоо юу ч болоогүй. Дээрх товчнуудыг дарж үз 🙂
🛠 Ахисан түвшин: командаар удирдах (C програмтай ижил)
